# Seawyn Website

Production homepage for Seawyn — an Indian import/export company.

Open `index.html` in a browser. No build step or framework required.

## Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts (Inter)

## Structure

│
├── index.html

├── css/

## Features

- Sticky header with products dropdown and mobile menu
- Hero, Who We Are, core strengths, difference, promise, and contact sections
- Scroll-triggered entrance animations via IntersectionObserver
- Responsive layout from 1920px down to 375px
