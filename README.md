# Seawyn Website

Static website for Seawyn — Indian spices, pulses, and grains export.

Open with a local server (or GitHub Pages). No build step required.

## Pages

- `index.html` — home
- `spices.html` — spices & masala
- `pulses.html` — pulses & grains

## Structure

```text
seawyn-website/
├── index.html
├── spices.html
├── pulses.html
├── css/style.css
├── js/layout.js
├── js/script.js
├── partials/
│   ├── header.html
│   ├── site-end.html
│   └── inquiry.html
└── assets/
```

## Features

- Shared header, footer, and enquiry CTA via `partials/`
- Spices and pulses product pages
- Enquiry form modal
- Responsive layout
